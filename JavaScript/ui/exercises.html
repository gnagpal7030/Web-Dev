JavaScript DOM and Events: 10 Exercises

Use the examples in DOM Fundamentals and Most Used JavaScript Events as references. Create a separate HTML page for your solutions and test each exercise in the browser.

1. Find elements in the DOM

Add a heading with an ID, three paragraphs sharing a class, and a button. Use getElementById to find the heading, querySelector to find the first paragraph, and querySelectorAll to find all three. Log the elements and the number of paragraphs in the console.

2. Inspect and update attributes

Create a text input with a type, value, and placeholder attribute. Use getAttribute, hasAttribute, and setAttribute to inspect and update it. Add a second button that removes the value attribute with removeAttribute.

3. Inspect nodes and tags

Select a heading that contains plain text. Display its tagName, nodeType, and first child's nodeType and nodeValue on the page. Confirm that the heading is an element node and its text is a text node.

4. Compare text and HTML content

Create a container with a paragraph, a nested span, and a hidden paragraph using display: none. Log the container's innerText, textContent, and innerHTML. Observe how hidden text and HTML tags appear in each result.

5. Change content and input values

When a button is clicked, update a heading with textContent, replace a card's contents with innerHTML (include a list), and change a text input's value. Add a CSS class to style the newly inserted content.

6. Respond to mouse events

Make a colored box respond to click and dblclick with different messages and background colors. Also handle mouseenter and mouseleave: report each event and restore the original color when the pointer leaves.

7. Track keyboard and live input

Add a text input. Listen for keydown and keyup and log the pressed key and its code. Use the input event to display the current value as the user types.

8. Handle form and focus events

Build a form with a name input, a country select, and a submit button. Use focus and blur to change and reset the input's border, change to show the selected country, and submit to show the entered name. Call event.preventDefault() so submitting does not reload the page.

9. Build a live character counter

Create a message field with a 100-character limit and a live counter. Update the counter on every input event and show a warning when fewer than 10 characters remain. Use a form submit handler with preventDefault to display the final message. Try selecting a value in a dropdown and report it with a change handler.

10. React to page and window events

Use DOMContentLoaded to initialize a status message and window.load to report that the page and its resources have finished loading. Listen for resize and display the current window width using window.innerWidth. Verify the resize message changes when you resize the browser.

11. Create a form

Add Js to existing form and print all the information when submit button is clicked.
