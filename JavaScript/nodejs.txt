What is NPM ?
Node Package Manager - to manage packages

What is package.json and package-lock.json ?
package.json - file that describes our project like name of the project, version, dependencies, scripts etc.

package-lock.json - file generated by NPM CLI - provides a deterministic and exact record of a project's dependency tree. package.json defines the version changes with ^ or ~ but this file pins down precise vesion, source and integrity hash of every installed package

HTTP Module - Module that enables you to create HTTP servers and make HTTP requests

File System - Module that lets you work with file on your computer - Supports I/O operations.

OS Module - Module that lets you interact with underlying operating system.
